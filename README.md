# 암기 도우미

사진이나 글로 넣은 자료를 암기 단위로 정리하고, 전체 내용을 다양한 형태로 시험 보고, 학습 정도를 과목별로 보여주는 개인 암기 웹앱입니다. GitHub Pages에서 `index.html`로 바로 실행됩니다.

## 구조
- **과목** → **단어 암기**(용어 ↔ 뜻 카드) / **내용 암기**(단원 → 사진·글 자료)
- 사진 → OCR(원문 보존) → AI 문맥 보정(교정만 허용, 지식 추가 금지를 코드로 검사) → 중요 내용 추출 → 요약 → 시험 준비까지 자동
- 암기 포인트마다 중요도(1~5)·빈칸 문장·빈칸 정답(핵심어만)을 저장
- 시험: 핵심 약 45% · 중요 약 27% · 일반 약 18% · 보조/세부 나머지. 핵심·중요 내용은 매번 출제, 세부는 돌아가며 출제
- 모든 문제는 품질 검증(자료 근거·명확성·정답 단일성·사소함·논리·중복)을 통과해야 출제되고, 떨어지면 다시 생성
- 모든 문제에는 근거가 된 자료 원문(`sourceExcerpt`)이 저장되고 결과 화면에 표시됨
- 요약본의 **빈칸 학습**: “대한민국의 수도는 [      ]이다.” → 확인하면 [서울]만 표시
- 데이터는 이 기기 브라우저의 IndexedDB에 저장

## 교재 사진 → 학습 문서 (v4)
사진 한 장이 다음 순서로 처리됩니다. 원본 사진은 그대로 보관하고, 보정한 이미지는 따로 저장합니다.
1. **이미지 전처리** (`imagePreprocess.js`): 색 글씨는 살리는 잉크 채널 → 조명 평탄화 → 대비 → 기울기(±5°) → 표 테두리로 원근 보정 → 변형 A(회색조)/B(Otsu)/C(진한 글자만)
2. **레이아웃 분석** (`layoutAnalysis.js`): 표 괘선으로 제목 / 질문 / 라벨(핵심 내용·신념화) / 본문 칸 / 쪽 번호 영역을 나눔
3. **다중 OCR + 합의** (`ocr.js`, `ocrConsensus.js`): 영역별로 변형 B·C를 읽고, 둘이 다르면 A(표가 없는 사진은 원본까지) 추가 → 줄 맞추기 + 낱말 투표
4. **정리** (`docCleanup.js`): 워터마크(사선 이름/날짜·시각) · 쪽 번호 · 뒷면 비침 잡음 제거, 기호 정리, 문서 안 빈도로 용어 통일(대할민국→대한민국). 모두 기록을 남김
5. **구조 복원** (`docStructure.js`): 제목 · 질문(번호·★·태그) · 대제목 · 소제목 · 본문 · 신념화 → `structuredContent` (JSON) + `finalText`(아래 형식) / `rawText`는 OCR 그대로
6. **AI 문서 분석** (선택, `ai.analyzeDocument`): 원본 이미지 + 영역별 OCR + 이전 쪽 구조를 보내고, 돌아온 구조를 OCR 줄과 한 줄씩 맞춰 **교정만** 받아들임 (근거 없는 줄은 확인 대기, 빠뜨린 줄은 되살림)
7. **학습 데이터** (`structureLearning.js`): 질문과 연결된 내용 = 핵심(5), 핵심 내용 칸 = 중요(4), 신념화 = 일반(3, 분류 ‘신념화’). 빈칸 정답은 구절만 (콜론 정의 > 따옴표 > 가운뎃점 나열 > 괄호 나열 > 날짜 > 숫자 > “…하는 것”)

`finalText` 형식 (직접 고쳐도 구조가 유지됨):
```
[제목] 우리가 지켜야 하는 대한민국 (1-3. 대한민국을 수호하는 국군)
[질문] Q3. (★민주주의와 헌법수호) 군인이 … 의미는 무엇인가?
[핵심 내용]
1. 국가와 군대의 관계
- 국가와 헌법
대한민국 헌법 제5조 제2항에 …
[신념화]
● 국가와 국민은 운명공동체로서 …
```
`ocr-test.html`: 사진(과 정답 전사본 JSON)을 넣어 단계별 결과·글자 오류율·구조 정확도를 확인하는 디버그 페이지.

## AI 연결 (선택)
AI가 없어도 모든 기능이 동작합니다(기본 출제는 자료 문장만 사용).
AI를 쓰려면 **API 키를 앱 코드에 넣지 말고**, 키를 보관하는 서버를 따로 둡니다.
1. `ai-proxy-worker.example.js`를 Cloudflare Workers 등에 올리고 키를 서버 환경변수에 저장
2. 앱의 ⚙ 설정 화면(또는 `config.js`의 `AI_API_URL`)에 그 서버 주소만 입력

## 파일
| 파일 | 역할 |
|---|---|
| `storage.js` | IndexedDB (v2: 단어 항목·암기 포인트 추가, v1 데이터 자동 이전) |
| `textAnalysis.js` | AI 없이 동작하는 한국어 분석 (조사, 유사도, 자모 편집거리, 중요도·빈칸 기본 분석) |
| `imagePreprocess.js` / `layoutAnalysis.js` | 사진 보정, 표 괘선 기반 영역 나누기 |
| `ocrConsensus.js` / `docCleanup.js` | 변형별 OCR 합의, 워터마크·쪽 번호·잡음 제거와 용어 통일 |
| `docStructure.js` / `docPipeline.js` | 교재 구조 JSON ↔ 글, 사진→문서 전체 흐름 |
| `structureLearning.js` | 구조 기반 암기 포인트·중요도·구절 빈칸 |
| `ocrDebug.js` / `ocr-test.html` | OCR 확인용 지표·디버그 페이지 |
| `ocrCorrection.js` | AI OCR 보정 제안을 한 건씩 검사해 적용/확인 요청/거부 |
| `questionQuality.js` | 문제 품질 검증 (8가지 검사 + 나쁜 문제 패턴 차단) |
| `learning.js` | 학습 정도 계산, 암기 포인트 추출·동기화, 학습률 |
| `wordStudy.js` | 단어 항목 관리, 단어 문제 만들기 |
| `quizGenerator.js` | 내용 시험 조립 (문제 수 결정, 커버리지, 랜덤화) |
| `quiz.js` / `quizResult.js` / `wrongAnswers.js` | 시험 세션·채점, 결과, 오답 기록 |
| `ai.js` | AI 호출 전담 (근거 검증 포함) |
| `summary.js` | 단원 요약본 |
| `ui.js` / `uiQuiz.js` | 화면 |
